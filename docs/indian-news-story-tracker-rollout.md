# Publisher feeds and Story Tracker rollout

The admin RSS feed list is the publication source. An active feed is fetched when it has a configured publisher domain and returns direct article URLs on that domain. Google News and Reuters links remain excluded. An article's subject, language, or AI country classification does not decide whether it is published. Inactive feeds stop fetching; articles already published from them remain visible.

Production schema: `2026-09-source-attribution-and-digest.sql`, `2026-09-indian-sources-story-tracker.sql`, `2026-09-admin-added-feeds.sql`, `2026-09-story-tracker-ai-summaries.sql`, `2026-09-publish-admin-rss-feeds.sql`, `2026-09-rss-restore-audit.sql`, and `2026-09-ai-suggested-stories.sql` have been applied to the configured Hostinger database. The `geo_status` column is retained for older records but no longer controls publication.

To recover saved articles written before feed attribution, first run `node scripts/restore-legacy-news.mjs` for a dry run, then stage an audited batch with `node scripts/restore-legacy-news.mjs --apply --limit=1000`. The script prints a run ID; `node scripts/restore-legacy-news.mjs --rollback=<run-id>` restores the previous feed, domain, and status values if they have not changed since that run. Each stage is capped at 5,000 inspected rows. The script matches direct article URLs to configured publisher domains, assigns a feed, and publishes rows previously held solely by AI classification. It keeps manually archived articles archived. Run `--link-only` as a dry run, then with `--apply`, to connect exact RSS item URLs from the four latest completed fetches to their article IDs.

For a new database, apply the migrations in order, configure publisher RSS feeds in Admin → RSS Feeds, then run RSS fetching. Story Tracker uses GPT-6 Luna to group reports and create short, cited summaries; it does not decide article eligibility. If using external cron, call `POST /api/cron/story-tracker` with `Authorization: Bearer <CRON_SECRET>` after RSS fetching.

The trending analysis chooses one story per category from a successful GPT-6 Luna ranking, generates its source-linked summary, and saves it in `ai_suggested_stories`. AI News and the Story Tracker detail route show these completed selections only. A failed AI ranking does not create a recency-based suggestion. The configured Hostinger analysis on 2026-09-29 created one sourced pick in each of the six populated categories.
